# G-код ЧПУ

Просмотр траектории G-кода (Fanuc 0i-MF Plus), простой чертёж и генерация параметрических программ.

## Как получить APK

Каждый push в `main` запускает сборку в GitHub Actions. Готовый APK появляется в разделе **Releases** (справа на странице репозитория) — скачайте файл `GcodeViewer-*.apk` и установите.

## Как обновить приложение

Замените файл `app/src/main/assets/index.html` новой версией страницы и сделайте commit — через пару минут в Releases появится новый APK. Он ставится поверх старого, чертёж и настройки сохраняются.

Сохранённые программы лежат в `Загрузки/CNC`.
