# G-код ЧПУ

Просмотр траектории G-кода (Fanuc 0i-MF Plus), простой чертёж и генерация параметрических программ.

## Как получить APK и EXE

Каждый push в `main` запускает сборку в GitHub Actions. Готовые файлы появляются в разделе **Releases** (справа на странице репозитория):

- `GcodeViewer-*.apk` — для Android, скачайте и установите;
- `GcodeViewer-*.exe` — для Windows 10/11 (64-бит), установка не нужна, просто запустите. Нужен Microsoft Edge WebView2 Runtime — в Windows 10/11 он обычно уже есть; если нет, программа предложит его скачать. F11 — полноэкранный режим.

## Как обновить приложение

Замените файл `app/src/main/assets/index.html` новой версией страницы и сделайте commit — через несколько минут в Releases появятся новые APK и EXE (обе версии собираются из этого же файла). APK ставится поверх старого, EXE достаточно заменить; чертёж и настройки сохраняются.

Сохранённые программы лежат в `Загрузки/CNC` на Android и в `Документы\CNC` на Windows.
