Фото чертежа, импорт и экспорт
Claude прочитает размеры с фото и построит чертёж вместе с глубинами, отверстиями и резьбами. Работает в веб-версии на claude.ai с интернетом.
Ключ API Claude (необязательно)
С ключом фото распознаётся прямо в приложении: нужен интернет и ключ с console.anthropic.com (оплата по тарифу API, отдельно от подписки). Ключ хранится только на этом телефоне. Без ключа фото отправится в приложение Claude, а его ответ вставьте в поле выше.
Верх детали — Z0, низ — Z−H. Назначьте каждому контуру роль и глубину, отметьте стенки нажатием на рёбра — «Операции по 3D-модели» соберут программу сами.
